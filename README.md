# Chimpanzé (iPhone)

**EN:** Script behind the **Chimpanzé** shortcut (Shortcuts app) that downloads videos from YouTube, Instagram, TikTok, X and more straight to the iPhone, using the free **a-Shell** app. It always picks the best quality the iPhone Photos app accepts.

**PT:** Script usado pelo atalho **Chimpanzé** do app Atalhos para baixar vídeos (YouTube, Instagram, TikTok, X e outros) direto no iPhone, usando o app gratuito **a-Shell**. Baixa sempre na melhor qualidade que a galeria do iPhone aceita.

## Install or update / Instalar ou atualizar (a-Shell)

```
curl -L -o ~/Documents/chimp.py https://raw.githubusercontent.com/johnmaacedo/chimpanze-ios/main/chimp.py
```

## Manual use / Uso manual

```
python3 ~/Documents/chimp.py "https://..."
python3 ~/Documents/chimp.py atualizar
```

**Instagram:** put a `cookies.txt` (exported from your logged-in browser) in the a-Shell folder. / coloque um `cookies.txt` (exportado do navegador logado) na pasta do a-Shell.
