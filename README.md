# Chimpanzé (iPhone)

Script usado pelo atalho **Chimpanzé** do app Atalhos para baixar vídeos
(YouTube, Instagram, TikTok, X e outros) direto no iPhone, usando o app gratuito **a-Shell**.
Baixa sempre na melhor qualidade que a galeria do iPhone aceita.

## Instalar ou atualizar (no a-Shell)

```
curl -L -o ~/Documents/chimp.py https://raw.githubusercontent.com/johnmaacedo/chimpanze-ios/main/chimp.py
```

## Uso manual

```
python3 ~/Documents/chimp.py "https://..."
python3 ~/Documents/chimp.py atualizar
```
